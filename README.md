# athakar

صفحة أذكار الصباح والمساء، تعمل على الجوال وتُضاف إلى الشاشة الرئيسية وتعمل بلا إنترنت.

## المزايا

- تختار الصباح أو المساء تلقائيًا حسب الوقت (من الساعة 3 فجرًا حتى 3 عصرًا صباح، وما بعده مساء)، ويمكن التبديل يدويًا.
- النقر على الذكر يُنقص عدد مراته، ويُعلَّم بـ«تمّ» عند الانتهاء، ويُحفظ التقدّم حتى بداية الجلسة التالية. زر «إعادة العدّ» يصفّر الوقت الحالي.
- الآيات بالرسم العثماني بخط Amiri Quran مع أرقام الآيات، والأذكار بخط Amiri.
- وضع ليلي تلقائي.

## الملفات

| الملف | الغرض |
|---|---|
| `index.html` | الصفحة والأذكار |
| `sw.js` | الحفظ للعمل بلا إنترنت (غيّر `CACHE` عند كل تعديل) |
| `manifest.webmanifest` | بيانات التثبيت على الشاشة الرئيسية |
| `fonts/` | خطّا Amiri وAmiri Quran (رخصة SIL OFL، انظر `fonts/OFL.txt`) |

## إضافة ذكر

كل ذكر عنصر `<li>` في `index.html`:

```html
<li class="thikr" data-count="3"><div class="text">نص الذكر</div></li>
```

- `data-count`: عدد المرات.
- `class="am"` للصباح فقط، و`class="pm"` للمساء فقط، وبدونهما يظهر في الوقتين.
- `class="verse"` للآيات.

## المصادر

نص الآيات من [quran-json](https://github.com/risan/quran-json) (رواية حفص، مصحف المدينة)، مع تحويل علامات التنوين المتتابع إلى ترميز يونيكود القياسي ليظهر صحيحًا بخط Amiri Quran.
